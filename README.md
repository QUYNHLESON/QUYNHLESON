# 👋 Bienvenue sur mon GitHub !

Spécialiste en analyse de données multi-sources, je maîtrise Power BI, Python et SQL pour explorer, visualiser et interpréter des données complexes. 

Chez RATP Infrastructures, j’ai automatisé des processus et conçu des tableaux de bord permettant d’identifier rapidement les anomalies et d’améliorer la fiabilité des systèmes.

Mes compétences s’appliquent aussi aux domaines du marketing, de la finance et de la gestion de projet.
